What I'm building

NodusDB is an embedded database for Python. You install it with pip install nodusdb and it runs inside your process, with no server and no JVM to install. It holds its state in memory, so a read takes microseconds. Every change goes into one ordered log. The log can be shipped to object storage as a signed chain, and the same log is written out as an Iceberg table, so replicas, history and analytics all read from it.

The engine is written in Java and compiled with GraalVM Native Image into one shared library. Its only dependency is the JDK. It is open source under the Apache License 2.0, and every design decision is written down in the repository with its reason.
