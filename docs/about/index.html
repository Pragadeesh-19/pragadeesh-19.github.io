What I'm building#

NodusDB is an embedded database for Python. You pip install nodusdb and it runs inside your process, with no server and no JVM to install. It holds live state in memory, so a read costs microseconds. Every change goes into one ordered log, and that log is shipped to object storage as a signed chain and as an Iceberg table, so replicas, history and analytics all come from the same place.

The engine is written in Java, compiled with GraalVM Native Image into one shared library, and the only dependency it has is the JDK. It is open source under the Apache License 2.0. Every design decision is written down in the repository with its reason, and the essays here are the longer versions of those notes.
