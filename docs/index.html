Building NodusDB
Writing About GitHub RSS

I'm Pragadeesh. I build NodusDB, an embedded database for Python that keeps live state in memory and writes its log to your own S3 bucket as an Iceberg table. One log gives you the replicas, the history and the analytics, with no server in between.

This is where I write down how it works and what went wrong along the way. You can try it with pip install nodusdb.
