I'm Pragadeesh. I'm building NodusDB, an embedded database for Python. It keeps its state in memory and can ship its log to an S3 bucket, where the same log is also an Iceberg table.

I write here about how it works and what goes wrong while I build it. To try it: pip install nodusdb.
